# Daten zum Sprechen bringen

Komplettpaket zur Unterrichtsreihe **Tabellenkalkulation mit Excel** am Umfrageprojekt „Mediennutzung" (Gymnasium, Jahrgang 10).

**▶ Live: https://stefanwjvenekamp-cloud.github.io/daten-zum-sprechen-bringen/**

Alle Dateien sind eigenständige HTML-Seiten und laufen offline im Browser – keine Internetverbindung, kein Office nötig.

## Inhalt

| Datei | Inhalt |
|---|---|
| `index.html` | Landingpage mit allen Links |
| `01_Praesentation.html` | Der Vortrag (17 Folien + 5 Anhangsfolien, mit Sprechernotizen) |
| `02_Handout.html` | Kompakt-Handout fürs Kollegium |
| `00_README.html` | Bedienung, Tastenkürzel, Pflichtaspekt-Übersicht |
| `fernbedienung.py` | Handy als Fernbedienung + Notizen-Anzeige (lokaler Mini-Server, nur Standardbibliothek) |
| `Material/AB1_Excel-Grundlagen.html` | Arbeitsblatt: Zelllogik, Bezüge, Formeln, Kennwerte |
| `Material/AB2_Fragebogen-Entwicklung.html` | Arbeitsblatt: eigene Fragebogen-Items entwickeln |
| `Material/AB3_Auswertung-Visualisierung.html` | Arbeitsblatt: von der Strichliste zum Diagramm |
| `Material/Fragebogen-Vorlage.html` | Druckbarer Beispiel-Fragebogen „Mediennutzung" |
| `Material/Bewertungsraster.html` | Bewertung: Produkt, Prozess, Präsentation, Reflexion |

## Bedienung der Präsentation

`→` / `Leertaste` weiter · `←` zurück · `S` Sprechernotizen · `F` Vollbild · `P` Druck-/PDF-Ansicht

## Handy als Fernbedienung

`python3 fernbedienung.py` im Kolloquium-Ordner starten (Laptop + Handy im selben WLAN oder im Handy-Hotspot, Internet nicht nötig). Laptop: angezeigte Präsentations-Adresse öffnen · Handy: angezeigte `/remote`-Adresse öffnen → große Weiter/Zurück-Tasten, Foliennummer und Sprechernotizen auf dem Handy. Alternativ funktioniert jeder USB-Presenter (Bild auf/ab) ohne Zusatzsoftware.

> Die in der Reihe gezeigten Beispieldaten sind exemplarisch.
