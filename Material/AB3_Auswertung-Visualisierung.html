Von der Strichliste zum Diagramm

Schritt für Schritt in Microsoft Excel – mit den echten Daten eurer Klasse
1

Daten eingeben

Erste Zeile = Spaltenköpfe, danach eine Zeile pro Wert/Person. Tippt eure Strichlisten-Ergebnisse ein.

2

Daten bereinigen

  • Komma statt Punkt verwenden (1,5) – sonst erkennt Excel Text statt Zahl.
  • Leere Zellen: bewusst entscheiden (leer lassen, nicht „0“ eintragen, wenn keine Angabe).
  • Einheit vereinheitlichen (alles in Minuten).
  • Ausreißer prüfen: ist „1200“ ein Tippfehler?
Achtung: Steht eine Zahl linksbündig in der Zelle, ist sie meist als Text gespeichert und wird nicht mitgerechnet → Format prüfen.
3

Kennwerte berechnen

Schreibe die Formeln in freie Zellen unter den Daten (Bereich anpassen, z. B. B2:B29):

KennwertFormel
Mittelwert=MITTELWERT(B2:B29)
Minimum / Maximum=MIN(B2:B29) · =MAX(B2:B29)
Spannweite=MAX(B2:B29)-MIN(B2:B29)
Standardabweichung=STABW.S(B2:B29)
Anzahl (n)=ANZAHL(B2:B29)
4

Diagramm erstellen

Daten markieren → Menü Einfügen → Diagramm → Typ wählen:

  • Kategorien vergleichen → Säulen-/Balkendiagramm
  • Anteile am Ganzen → Kreisdiagramm
  • Verlauf über Zeit → Liniendiagramm
5

Standards anwenden (Pflicht!)

Ein gutes Diagramm versteht man ohne mündliche Erklärung:

aussagekräftiger Titel   Achsen beschriften inkl. Einheit
passender Diagrammtyp   sparsame, einheitliche Farben   Datenbasis n = angeben

So geht's: Diagramm anklicken → Diagrammelemente (＋) → Achsentitel & Diagrammtitel aktivieren und beschriften.
6

Export nach PowerPoint

  1. Diagramm in Excel anklicken → Strg+C.
  2. In PowerPoint auf der Folie → Strg+V einfügen.
  3. Empfehlung: beim Einfügen „Grafik“ wählen → das Diagramm bleibt stabil, auch ohne die Excel-Datei.
Fertig, wenn …  alle Kennwerte berechnet sind   das Diagramm allen 5 Standards entspricht   ihr eine Kernaussage in einem Satz formuliert habt.
